## Key Objectives

- Implement the U-Net architecture for semantic image segmentation.
- Detect and segment pavement cracks from road surface images.
- Train a deep learning model using the CRACK500 dataset.
- Generate pixel-level segmentation masks.
- Evaluate segmentation performance using TP, TN, FP, and FN metrics.
- Compare predicted masks with ground-truth annotations.
- Visualize probability maps and segmentation results.
- Develop a robust solution for automated infrastructure inspection.
